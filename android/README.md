# Smart Traffic — Android

Android control-center application for the Smart Traffic Monitoring System.

## Planned stack
- Kotlin
- Jetpack Compose
- ViewModel + StateFlow
- Navigation
- Repository/use-case architecture
- Android NDK/JNI for performance-critical C++ vision code

## Feature areas
- Dashboard
- Live Camera
- Evidence / Images
- Device Control
- Device Connections
- Traffic Rules
- Watchlist / Reports
- Alerts
- System Settings
- Application Settings

The Android module is intentionally separated from ESP32 firmware and the native vision engine.
